# Website Design Review

## Workflow

1. Identify the target page, its users, primary task, and existing brand cues. Inspect the relevant page and shared components before proposing changes.
2. Review desktop and narrow-screen layouts. Use a browser screenshot when available; otherwise label conclusions as source-based.
3. Check hierarchy, spacing, typography, color contrast, alignment, density, content clarity, focus/hover states, and consistency across related pages.
4. Prioritize issues that block the main task or make the interface hard to understand. Separate observed defects from design preferences.
5. If asked to improve the page, make the smallest coherent change that supports the main task. Recheck both viewport sizes and the changed interactions.

## Design principles

- Keep the existing brand recognizable unless the user requests a new direction.
- Prefer a small set of reusable colors, type roles, spacing steps, radii, and control styles over one-off decoration.
- Make primary actions easy to find; give secondary actions lower visual weight.
- Preserve readable line lengths, sufficient contrast, clear focus indication, and comfortable touch targets.
- Respect reduced-motion preferences and avoid motion that carries essential information by itself.
- Use real product content and states when available. Do not add decorative UI that competes with the task.
- For this repository, follow `.cursor/skills/pinoyproto3d-website-development/SKILL.md` for the established PinoyProto 3D visual language and page conventions.

## Report format

For an audit, list each finding with page, location, user impact, and a concrete recommendation. Mark subjective refinements as suggestions, not bugs. For implementation, summarize the visual changes and how they were checked.
