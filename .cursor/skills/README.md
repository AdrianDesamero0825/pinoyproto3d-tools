# Website quality skills

Use the focused skill that matches the work:

- `website-design-review` — aesthetics, visual hierarchy, UX, and responsive design.
- `website-performance` — load speed, asset size, rendering, API payloads, and Core Web Vitals.
- `website-bug-finder` — defect discovery, reproduction, root cause, and security review.
- `website-tester` — local/browser test plans and interaction validation.
- `website-accessibility-seo` — accessibility, semantics, metadata, and public discoverability.
- `full-website-quality` — coordinate a complete website audit or production-readiness pass.
- `pinoyproto3d-website-development` — existing project-specific implementation conventions.

Each skill has its own `SKILL.md`. The focused skills can be used independently; `full-website-quality` ties them together for broad reviews.
